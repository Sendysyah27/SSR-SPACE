# P2-R1: Riwayat grup per hari

## Problem

List transaksi SSR tampil sebagai deretan baris tanpa kepala hari,
sehingga sulit menjawab pertanyaan sederhana: kemarin keluar berapa,
hari ini sudah catat apa. Scan vertikal panjang melelahkan di HP kecil.

## Pola Ollo

Ollo 1.6.0 mengelompokkan Transaction Log per hari (satu kepala tanggal,
baris di bawahnya). Referensi alur saja, tanpa salin kode atau aset.

## Adaptasi SSR

Helper murni `groupDayBuckets(items)` di `lib/services/tx_day_group.dart`:
urut date DESC lalu created_at DESC, kelompokkan per kunci `yyyy-MM-dd`.
Satu widget header reuse (`SectionCard` + teks tanggal + hitung baris +
total hari via `amt()`, mask-aware) dipakai di Transaksi, Laporan, dan
Riwayat Dompet. Transaksi tanpa tanggal masuk bucket paling bawah dengan
label netral. Tidak ada sticky rumit, tidak ada badge baru.

## Data dan prefs

Tanpa migration. Tanpa prefs baru. Murni dari list yang sudah dimuat
lewat service resmi. Label tanggal ikut `monthLabel`/`dayLabel` dan bahasa
app (ID/EN).

## Edge cases

Bulan kosong: EmptyView lama, bukan grup kosong. Beda zona waktu: kunci
dari string date yang sudah dinormalkan service. Transfer: tampil sebagai
satu baris di hari tanggalnya, nominal ikut aturan ringkasan yang ada.
Ganti workspace atau bulan: kelompokkan ulang dari data aktif.

## Daftar test

Urut desc lintas hari dari tanggal buatan. Satu hari berisi in, out, dan
transfer tetap satu grup. Null date jatuh ke bucket bawah. List kosong
tanpa grup. Label ID dan EN berbeda benar.

## Dampak Supabase dan RLS

Tanpa migration. Tidak ada baca atau tulis baru, hanya mengelompokkan
data yang sudah lewat RLS yang ada.
